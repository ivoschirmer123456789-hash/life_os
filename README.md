# LIFE OS 15.1.0 — Intelligent Experience

Projeto completo do LIFE OS, com `index.html` diretamente na raiz para GitHub/Vercel.

## Destaques desta versão

- Projetos com revisões adaptativas, relatórios honestos e simulação de replanejamento **com confirmação**.
- LIFE AI local conectada aos relatórios dos Projetos, respeitando as permissões de contexto existentes.
- Cópias locais de recuperação para dados críticos e opção explícita de restaurar Projetos.
- Registro de acompanhamento em Fitness e revisões curtas na trilha de Estudos.
- Melhoria de clareza dos controles, mantendo preto/laranja, Free/Pro e navegação mobile.

## Antes de publicar

1. Faça backup do projeto que já está funcionando.
2. Extraia este ZIP na raiz do repositório (não coloque o projeto inteiro dentro de uma subpasta).
3. Faça deploy em uma instalação de teste na Vercel.
4. Confirme em uma conta de teste: login, Projetos → Criar → Revisar → Simular, recuperação local, plano de Estudos, ficha de Treino, assinaturas e sincronização entre dois dispositivos.
5. Só depois promova para seu domínio principal.

**Arquivos:** 100. **Relatório:** `QA_REPORT_15.1.0.md` (inclui a auditoria da versão 15.1.0).

O sistema preserva os arquivos originais de Supabase, pagamento e banco; esses fluxos requerem avaliação real em produção/staging.
