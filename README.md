# LIFE OS 9.1.1 — Calm Hierarchy Edition

Versão focada em reduzir excesso visual sem remover capacidades. A interface mostra primeiro o que é necessário para decidir e agir; contexto, métricas e ferramentas secundárias aparecem sob demanda.

## O que mudou
- Workspaces PRO/OWNER deixam métricas e ferramentas secundárias recolhidas em “Ver contexto” e “Mais ferramentas”.
- Home PRO reduz atalhos principais de 6 para 4 e remove o card redundante de status do sistema.
- Meu Dia mostra até 5 itens antes de “ver todos”.
- A leitura lateral do dia virou “Leitura rápida” recolhível.
- Inbox mostra até 3 capturas e cada item exibe apenas “Organizar”; destinos aparecem ao abrir.
- Prévias de listas nos workspaces foram reduzidas para 3 itens; Favoritos mostra até 6.
- Grades densas de métricas/recursos passaram de quatro colunas para no máximo duas no workspace principal.
- Mobile mantém uma coluna nas decisões importantes.
- Nenhuma função foi apagada: o conteúdo secundário continua acessível por divulgação progressiva ou Studio Mode.
- PRO/OWNER permanecem prateado/platina; tema Dia permanece claro.
