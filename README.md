# LIFE OS 9.4.1 — Command Audit Edition

Revisão funcional da 9.4 com foco em comandos, botões, rotas e captura rápida. Mantém a organização Hub → Modo Foco → Mais opções.

## Correções desta revisão
- Parser de dinheiro não confunde mais horas/datas com valores.
- Frases como `gastei R$ 32,50 no lanche` passam a ser reconhecidas como gasto.
- Toque longo no mobile abre a prévia sem disparar o clique original ao soltar.
- Ação **ABRIR** da prévia só aparece quando o item é realmente clicável.
- Copiar nome ganhou fallback quando Clipboard API não estiver disponível.
- Título/build/cache atualizados para 9.4.1.

Veja `QA_REPORT_9.4.1.md` para a auditoria.
