# LIFE OS 14.6.2 — FREE Profissional / PRO Signature | revisão de funcionamento

Versão completa baseada na 14.6.1, preservando toda a identidade visual da FREE e PRO.

Correções:
- Guia de Estudos básico agora está incluído nas rotas permitidas do FREE; não volta à Home inesperadamente.
- Sessões temporárias de recuperação de senha não substituem o formulário de nova senha pelo portão de sessão.
- Identificação visual do build no PRO atualizada para 14.6.2.
- Proteção na lista de tarefas FREE caso uma tarefa antiga não tenha identificador.
- Cache PWA e links com versão 14.6.2 para evitar arquivos misturados.

Para instalar: extraia o ZIP e envie **o conteúdo da pasta** ao repositório GitHub, com `index.html` na raiz. Mantenha um backup antes de publicar.

**Nota:** estes testes são locais. Não confirmam as integrações Supabase, IA ou pagamentos reais na Vercel. Não altere tokens ou banco de dados sem testar o ambiente publicado.
