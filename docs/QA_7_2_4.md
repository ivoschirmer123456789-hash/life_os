# LIFE OS 7.2.4 — QA do fluxo PRO

Escopo: botões PRO, prévia contextual, comparativo de planos, fallback de clique, portal de modais, versionamento/cache e integridade estática.

Critérios:
- nenhum botão React contendo chamada PRO sem `onClick` na varredura estática;
- nenhuma chamada `openLifePro()` vazia;
- prévia e paywall renderizados fora do container `.v18` por portal quando `ReactDOM.createPortal` está disponível;
- fallback global de clique no runtime;
- fallback visual independente caso a camada React não seja materializada;
- arquivos do shell do service worker existentes;
- JavaScript ativo com sintaxe válida;
- CSS parseável;
- referências locais do `index.html` existentes.
